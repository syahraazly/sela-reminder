Sela adalah pengingat duduk tegak atau minum air putih di area island MacBook.

Cara memasang:

1. Download file `Sela.dmg` di bagian Assets.
2. Buka DMG, lalu drag Sela.app ke Applications.
3. Buka Sela, pilih jenis dan interval pengingat, lalu klik Mulai pengingat.

Memerlukan macOS 14 atau lebih baru. Paket berisi build Apple Silicon dan Intel; pengujian runtime saat ini dilakukan pada Apple Silicon.

Ini versi preview yang ditandatangani ad hoc dan belum dinotarisasi Apple. Preview ini dapat dibagikan melalui GitHub Releases tanpa sertifikat Developer ID, tetapi macOS dapat menahan aplikasi saat pertama dibuka.

Jika pengembang belum dapat diverifikasi, ikuti bagian instalasi di README dan [panduan Apple](https://support.apple.com/en-us/102445). Hanya lanjutkan jika kamu mempercayai sumber unduhannya.

File `.sha256` tersedia untuk memeriksa integritas unduhan. Tidak perlu memasang Swift, Xcode, atau menjalankan Terminal untuk memakai aplikasinya.
